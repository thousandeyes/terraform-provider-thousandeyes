# thousandeyes_endpoint_agent_to_server (Resource)

Manages a scheduled Endpoint Agent-to-Server test. Use `agent_selector_type` to choose all Endpoint Agents, specific agents, or agents selected by tags.

## Example Usage

```terraform
resource "thousandeyes_endpoint_agent_to_server" "example" {
  agent_selector_type = "all-agents"
  test_name           = "Example Endpoint Agent-to-Server test"
  server              = "www.thousandeyes.com"
  protocol            = "tcp"
  port                = 443
  interval            = 300
}
```

Choose one selector mode. `specific-agents` requires `agents`; `agent-tags` requires `tag_ids`; `all-agents` sends neither list. `max_machines` is optional and defaults to 25 in the API. The selector and other create-only properties require replacement when changed.

## Schema

### Required

- `agent_selector_type` (String) How Endpoint Agents are selected for this test: `all-agents`, `specific-agents`, or `agent-tags`.
- `server` (String) Target domain name or IP address.
- `test_name` (String) The name of the test.

### Optional

- `agents` (Set of String) Endpoint Agent IDs to use when `agent_selector_type` is `specific-agents`.
- `interval` (Number) Interval between test runs in seconds.
- `ip_version` (String) IP version used for the test. This setting requires replacement when changed.
- `is_enabled` (Boolean) Whether the test is enabled. The API enables tests by default.
- `is_prioritized` (Boolean) Whether the test is prioritized when the Endpoint Agent's test limit is exceeded. This setting requires replacement when changed.
- `max_machines` (Number) Maximum number of Endpoint Agents that can execute the test. If omitted, the API default of 25 applies.
- `port` (Number) Target port. The API default is 443.
- `protocol` (String) Protocol requested for the test.
- `tag_ids` (Set of String) Tag IDs used to select Endpoint Agents when `agent_selector_type` is `agent-tags`.
- `tcp_probe_mode` (String) Probe mode used when the protocol is TCP.

### Read-Only

- `aid` (String) Account group ID associated with the test.
- `created_date` (String) UTC date and time when the test was created.
- `has_path_trace_in_session` (Boolean) Whether path tracing runs within a TCP session.
- `id` (String) The ID of this resource.
- `is_saved_event` (Boolean) Whether the test is a saved event (private snapshot).
- `link` (String) Link to the test resource returned by the API.
- `modified_date` (String) UTC date and time when the test was last modified.
- `network_measurements` (Boolean) Whether network measurements are enabled.
- `test_id` (String) The unique ID of the test.
- `type` (String) The type of test returned by the API.
