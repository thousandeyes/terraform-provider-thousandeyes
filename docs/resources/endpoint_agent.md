# thousandeyes_endpoint_agent (Resource)

Manages an existing ThousandEyes Endpoint Agent. This resource is import-only because the API does not support creating Endpoint Agents. Import an existing agent by ID before managing it. Destroying the resource deletes the remote Endpoint Agent.

## Example Usage

```terraform
resource "thousandeyes_endpoint_agent" "laptop" {
  name         = "Alice laptop"
  license_type = "advantage"
  status       = "enabled"
}
```

Endpoint Agents must already exist before Terraform can manage them. The resource supports updating the name and supported license types, and enabling or disabling the imported agent through `status`. The `embed-wireless-advantage` and `embed-wireless-essentials` license types can be read after import but cannot be assigned. Destroying this resource deletes the agent from ThousandEyes.

## Schema

### Optional

- `license_type` (String) The license type assigned to the Endpoint Agent. The `embed-wireless-advantage` and `embed-wireless-essentials` license types can be read after import but cannot be assigned.
- `name` (String) The name of the Endpoint Agent.
- `status` (String) The desired status of the Endpoint Agent: `enabled` or `disabled`.

### Read-Only

- `id` (String) The ID of this resource.

## Import

In Terraform v1.5.0 and later, use an [`import` block](https://developer.hashicorp.com/terraform/language/import) providing `resource_id`.

```terraform
import {
  to = thousandeyes_endpoint_agent.laptop
  id = "123456"
}
```

Using `terraform import` command.

```shell
terraform import thousandeyes_endpoint_agent.laptop 123456
```
