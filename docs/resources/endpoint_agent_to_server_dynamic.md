# thousandeyes_endpoint_agent_to_server_dynamic (Resource)

Manages a dynamic Endpoint Agent-to-Server test. Agent selectors and other create-only settings require replacement when changed.

## Example Usage

```terraform
data "thousandeyes_endpoint_agent" "example" {
  agent_name = "Example laptop"
}

resource "thousandeyes_endpoint_agent_to_server_dynamic" "example" {
  test_name           = "Endpoint Webex"
  application         = "webex"
  interval            = 300
  agent_selector_type = "specific-agents"
  agents              = [data.thousandeyes_endpoint_agent.example.agent_id]
  max_machines        = 25
}
```

Supported applications are `webex`, `zoom`, and `microsoft-teams`.

## Agent Selection

`agent_selector_type` defaults to `all-agents`, which accepts neither `agents` nor `tag_ids`.
Use `specific-agents` with a nonempty `agents` set, or `agent-tags` with a nonempty `tag_ids` set.
Endpoint Agent IDs are strings. `max_machines` defaults to 25 for all selector modes.
Endpoint Labels and the legacy `agent-labels` selector are unsupported.

For selection by dynamic tags, create a `thousandeyes_tag` with `object_type = "endpoint-agent"`
and `type = "dynamic"`, and reference its ID in `tag_ids`.

## Updates and Import

Changes to `test_name`, `application`, `interval`, `protocol`, `tcp_probe_mode`, and `is_enabled`
update the existing test.

Changes to other configurable settings replace the test. Tests configured with
`is_enabled = false` may briefly be enabled during creation.
