# thousandeyes_endpoint_http_server (Resource)

Manages a scheduled Endpoint HTTP Server test. Agent selectors and other create-only settings require replacement when changed.

## Example Usage

```terraform
data "thousandeyes_endpoint_agent" "example" {
  agent_name = "Example laptop"
}

resource "thousandeyes_endpoint_http_server" "example" {
  test_name           = "Endpoint HTTP Server"
  url                 = "https://example.com"
  interval            = 300
  agent_selector_type = "specific-agents"
  agents              = [data.thousandeyes_endpoint_agent.example.agent_id]
  max_machines        = 25
}
```

The provider defaults a URL without a scheme to HTTPS. The returned HTTPS URL
and the configured bare hostname are treated as equivalent during refresh.

## Agent Selection

`agent_selector_type` defaults to `all-agents`, which accepts neither `agents` nor `tag_ids`.
Use `specific-agents` with a nonempty `agents` set, or `agent-tags` with a nonempty `tag_ids` set.
Endpoint Agent IDs are strings. `max_machines` defaults to 25 for all selector modes.
Endpoint Labels and the legacy `agent-labels` selector are unsupported.

For selection by dynamic tags, create a `thousandeyes_tag` with `object_type = "endpoint-agent"`
and `type = "dynamic"`, and reference its ID in `tag_ids`.

## Updates and Refresh

Changes to `test_name`, `url`, `interval`, `protocol`, `tcp_probe_mode`, and `is_enabled`
update the existing test. IPv6 and OS-default IP preferences require `protocol = "icmp"`;
other protocols require `ip_version = "V4_ONLY"`.

Other configurable settings require replacement because the
Endpoint HTTP update API does not accept them. A test configured with `is_enabled = false`
is created first, then disabled in a second API call.

The API does not return `password`, `has_ping`, or `has_traceroute`.
The provider retains these configured values, but cannot detect remote changes to them.
After import, configure these fields deliberately: differences may require replacement.
Passwords are sensitive and are retained in Terraform state.

The API returns `target_response_time` as `http_target_time`; the provider restores
both attributes from that response value.

This resource uses the Endpoint HTTP test API; headers, request bodies, and OAuth
settings from Cloud and Enterprise HTTP server tests are unavailable.

- `max_machines` (Number) Maximum number of agents that can execute the test. Defaults to 25.
