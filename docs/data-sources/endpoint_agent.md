# thousandeyes_endpoint_agent (Data Source)

Use this data source to look up an existing ThousandEyes Endpoint Agent by exact name. For more information, see [List Endpoint Agents](https://developer.cisco.com/docs/thousandeyes/list-endpoint-agents/).

## Example Usage

```terraform
data "thousandeyes_endpoint_agent" "laptop" {
  agent_name = "Alice's laptop"
}

output "endpoint_agent_id" {
  value = data.thousandeyes_endpoint_agent.laptop.agent_id
}

output "endpoint_agent_name" {
  value = data.thousandeyes_endpoint_agent.laptop.agent_name
}
```
